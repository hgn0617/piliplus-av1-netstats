上述为已有本地构建的哈希。重新签名、重新压缩或在不同工具链下重建会改变最终 IPA 哈希；构建脚本会输出当前包的检查记录。当前 iPhone 已安装并验证新版 IPA 的应用名为 `PiliPlus`，播放功能仍需在设备上实际检查。

Mac 的库替换和网速显示维护在对应目录，当前样式为无背景、紧凑间距、细描边，并可保存字号与位置偏好。
